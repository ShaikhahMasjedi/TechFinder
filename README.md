# 🛒 TechFinder

TechFinder is a comprehensive e-commerce web application dedicated to selling electronic products. It provides a seamless shopping experience for customers and a powerful management dashboard for administrators.

## 🚀 Project Idea & Overview
TechFinder bridges the gap between tech enthusiasts and electronics retailers. The platform supports two primary user roles:
1. **Customer:** Can browse products, search, manage their shopping cart and wishlist, place orders, and make secure purchases.
2. **Admin:** Has full control over monitoring the system, managing products, categories, orders, users, and viewing analytical dashboards.

---

## ✨ Key Features & Operations

### 👤 Authentication & User Management
* Secure Login & Registration
* Forgot Password, Reset Password, and Code Verification
* User Profile management & Profile information editing
* User Order History tracking

### 🛍️ Customer Operations & Shopping
* **Product Discovery:** Search products by name, price, and description.
* **Browsing Collections:** View categories, deals of the week, and new arrival products.
* **Product Details:** View full specifications, customer comments, reviews, and similar products.
* **Interactive Lists:** Add/Delete products to/from the **Favourite list** and **Shopping Cart**.
* **Checkout & Purchase:** "Buy Now" functionality, seamless shopping cart management, and secure payment processing.
* **Communication:** "Contact Us" feature to reach out for support.
* **Engagement:** Add comments and product reviews.

### ⚙️ Administrator Dashboard & Control
* **Dashboard:** Display an overview and analytical information about the project.
* **CRUD Operations (Add, Edit, Delete, Display):**
  * Products & Categories
  * Customers & Employees
  * System Orders monitoring
